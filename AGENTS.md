# AGENTS

## Introduction
This document provides an overview of the agents system used in the application.

## Installation
To install the agents, please follow the instructions below:

1. Clone the repository.
2. Run the setup script.

## Usage
After installation, the agents can be used as follows:

- Start the agents by running the command `start-agents`.
- Monitor agents performance using the `monitor-agents` command.
